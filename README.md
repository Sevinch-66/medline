# MedLine — Дәрігерге жазылу жүйесі

Жасыл-ақ дизайндағы медициналық орталықтың оқу веб-жобасы. HTML, CSS және JavaScript арқылы жасалған.

## Мүмкіндіктері
- Дәрігерлерді аты немесе мамандығы бойынша іздеу
- Мамандығы, тәжірибесі, бағасы бойынша сүзу/сұрыптау
- Дәрігер карточкасын ашу және қабылдауға жазылу
- Жеке кабинетте жазылуларды қарау және жою
- Қазақша/орысша интерфейс ауыстыру
- Жазылуларды браузердің `localStorage` қоймасында сақтау
- SQL дерекқор схемасының үлгісі `database/schema.sql` ішінде
- Телефонға бейімделетін responsive дизайн

## Іске қосу
1. Репозиторийді жүктеп алыңыз немесе ZIP архивін ашыңыз.
2. `index.html` файлын браузерде ашыңыз.
3. Сыртқы дәрігер фотосуреттері мен Google Fonts көрсету үшін интернет қажет. Негізгі бет пен фон интернетсіз де көрінуі тиіс.

## GitHub-қа жүктеу
1. GitHub-та жаңа repository ашыңыз, мысалы `medline-appointment-system`.
2. Осы папкадағы файлдарды репозиторийге жүктеңіз (немесе Git арқылы push жасаңыз).
3. GitHub Pages керек болса: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Маңызды ескерту
Бұл — оқу/демонстрациялық жоба. Жазылулар тек осы браузерде сақталады; нақты клиникада қолдану үшін серверлік API, дерекқорға қосылу, авторизация және жеке деректерді қорғау қажет. Көрсетілген мекенжай, телефон, дәрігерлер мен бағалар демонстрациялық мазмұн болуы мүмкін.
